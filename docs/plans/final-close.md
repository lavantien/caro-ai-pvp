# Final close plan v0.24 through v0.28

Consolidated execution plan issued 2026-11-05 under the remove-redundant-steps order. One engine state carries every remaining tag: after the collapse lever lands, no engine commit follows, so each release tag points at verdict and docs commits over the same frozen binary. The per-release verification batches collapse into one final batch, and every arena arm runs once on the freeze it judges.

## Rulings

1. No open-two reprice. The family census over 245 regate2 loss and win positions measured open-two cuts of 40, 60, and 80 demoting zero played top-3 moves on every loss pool while rank churn grows with the cut level (playground/sqstrength/out/family-loss.txt, family-win.txt), so the third square fix rides the search and solver seam inside the capability-removal ladder under the never-degrade law, per the 2026-10-28 standing rulings.
2. v0.24 gates on the hex chain only, per the roadmap line: hex noise floors, hex pass gates, hex ladder inversion checks at 2+1 and 3+2, then the tag. The square strength question gates v0.27 and v0.28, not v0.24, so the v0.24 tag lands as soon as the hex chain closes on the final freeze and never waits on the book, which hex never reads.
3. The hex passgate legs from the 2026-10-31 binary carry into the v0.24 verdict only if the collapse lever leaves the hex code path byte-identical, verified by diffing the lever commit against the shared engine files and the geometry-split constants. The hex medium 2+1 guard leg then re-runs alone on the final freeze. If the lever touches shared machinery, the whole hex table reruns on the final freeze. Decided mechanically per lever, never assumed.
4. The evalpair-21 and evalpair-32 deciding pairs are cut. The fitted weights were derived under an eval that no longer exists, the clean-window and boxed-ladder terms postdate the refit artifact, and the fitted set was already rejected at both controls in the v024 side-gate. The scaffold stays in force as shipped. The weights chain re-derives post-close if the reference-model redesign is ever taken up.
5. The book validations run the implemented superset shape: 1+0, 2+1, 3+2 pairs plus the 10+5 confirm, covering both the booktree preregistration plan and the book-gate law readings.
6. The closing ladder runs 1 repetition per control over all 4 controls, per the roadmap text. The five-tier certification grade was the v0.23 demand re-spec verification, consumed at the 2026-10-18 re-gate, and does not bind the close.
7. The grandmaster rungs run as dedicated arms, not merged into the closing ladder pair tables, so a v0.27 failure surfaces with a fix window instead of at v0.28 time.
8. The mutation re-gate covers internal/engine and internal/server on the final freeze and carries internal/rules and internal/vcf from the 2026-10-31 green, since only engine and config source and server test files changed since. The server scope stands because its killer suite was rebased; the rules and vcf suites are untouched.

## Serial machine schedule

1. Collapse lever lands with tests, regate3 checks it on 4 legs: the 3 failing square legs (hard 2+1, medium 3+2, easy 3+2) plus square hard 3+2 as the regression canary, the one passing leg nearest its threshold.
2. Freeze the binary. Mutation re-gate over engine and server runs here, before any expensive arena evidence, so a surviving mutant surfaces before the nights are spent.
3. Hex chain on the freeze: hex impact check per ruling 3, the guard leg if the carry holds or the full table if not, then the hex ladder at 2+1 and 3+2, 480 games. The v0.24 tag cuts after the verification batch confirms the tree.
4. Booktree funded build on the final engine, grandmaster standard, 2^36 nodes, reverify, resumable.
5. Book validation arms: short, confirm, cross, in the ruling 5 shape.
6. Final square passgate with the funded book, 6 legs: this one batch is the collapse close and the v0.25 strength gate rerun. The v0.25 tag cuts on green.
7. Ponder arena pair under its preregistration. The v0.26 tag cuts on its verdict.
8. Grandmaster pass rungs, 4 arms both seats, plus the 2-grandmaster ui tournament screenshots beside a live run. The v0.27 tag cuts on green.
9. Closing ladder, 1 repetition per control across 4 controls, 0 inversions required at 2+1, 3+2, 10+5, 1+0 recorded as thread-decided.
10. Final verification batch at the frozen HEAD: ci, fuzz, e2e, the mutation green already banked at step 2. README final state, evidence bundle, the v0.28 tag.

Steps 3 through 9 serialize on the machine. Docs, preregistrations, drivers, and tags overlap freely. Floor estimate: 11 to 17 machine-nights, dominated by the closing ladder and the mutation re-gate.
